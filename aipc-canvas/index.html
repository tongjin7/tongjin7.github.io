AIPC Canvas

个人自用的 AI 创作画布 · A personal AI creative canvas

AIPC Canvas 是作者自己部署、自己使用的 AI 创作画布，用来写剧本、做分镜、生成图片和视频。它基于开源项目 infinite-canvas（AGPL-3.0）修改而来，运行在作者自己的服务器上，不对外提供服务，也不接受其他用户注册。

AIPC Canvas is a self-hosted AI creative canvas used only by its owner for script writing, storyboarding, and image and video generation. It is a modified version of the open-source project infinite-canvas (AGPL-3.0). It runs on the owner's own server and is not offered as a service to anyone else.

Google Drive

画布可以把作者在画布里上传或生成的素材保存到作者自己的 Google Drive。它只申请 drive.file 权限，只能访问由它自己创建的文件，看不到 Drive 里的其他内容。

The canvas can store media that the owner uploads or generates into the owner's own Google Drive. It requests only the drive.file scope, so it can access only files it created and cannot see anything else in Drive.
