AIPC Canvas 隐私政策 · Privacy Policy

适用范围 · Scope

AIPC Canvas 是作者个人部署、只供自己使用的应用，没有其他用户。本政策说明它通过 Google API 获得的数据如何使用。

AIPC Canvas is a personal, self-hosted application used only by its owner; it has no other users. This policy describes how it handles data obtained through Google APIs.

访问的数据 · Data accessed

应用只申请 Google Drive 的 https://www.googleapis.com/auth/drive.file 权限，用于在作者自己的 Drive 里创建、读取和删除由本应用创建的文件，以及读取授权账号的邮箱地址用于显示连接状态。应用无法访问 Drive 中其他任何文件。

The application requests only the Google Drive scope https://www.googleapis.com/auth/drive.file. It uses it to create, read and delete files that the application itself created in the owner's Drive, and to read the authorized account's email address to show the connection status. It cannot access any other files in Drive.

数据的存储与使用 · Storage and use

OAuth 授权令牌和文件 ID 只保存在作者自己的服务器上，只用于把作者的素材存入和读出 Drive。数据不会出售、共享或转交给任何第三方，也不会用于广告或分析。

The OAuth tokens and file IDs are stored only on the owner's own server and are used only to save the owner's media to Drive and read it back. The data is not sold, shared or transferred to any third party, and is not used for advertising or analytics.

AIPC Canvas 对通过 Google API 获得的信息的使用和传输，遵守 Google API 服务用户数据政策，包括其中的「有限使用」要求。

AIPC Canvas's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

撤销授权 · Revoking access

可以随时在画布的设置里断开 Google Drive，或者在 Google 账号的第三方应用权限 页面撤销授权。撤销后应用将无法再访问这些文件，已存入 Drive 的文件会保留在你的 Drive 中。

You can disconnect Google Drive in the canvas settings at any time, or revoke access on your Google Account third-party access page. After revoking, the application can no longer access the files; files already saved remain in your Drive.

联系方式 · Contact

如有问题，请通过 Google 授权页面上显示的应用支持邮箱联系。

For questions, contact the app support email shown on the Google consent screen.
